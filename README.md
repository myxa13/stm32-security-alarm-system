# Security Home Sensor Module

## Описание проекта
Это система безопасности для домашнего использования, реализованная на микроконтроллере STM32F411CE с использованием радиомодуля NRF24L01 для беспроводной связи. Система позволяет создать сеть датчиков безопасности, которые могут передавать информацию о событиях (движении или открытии/закрытии) в центральный приемник.

## Архитектура системы
Проект поддерживает две роли:
1. **Приемник (Радио база)** - получает данные от передатчиков и выводит их через UART
2. **Передатчик (Датчики)** - собирает данные с датчиков и передает их по радио

## Схема подключения
### Основные компоненты:
- **STM32F411CE** - микроконтроллер
- **NRF24L01** - радиомодуль для беспроводной связи
- **Датчик движения PIR** (например, HC-SR501) 
- **Геркон-датчик** (например, Reed Switch)

### Подключение NRF24L01 к STM32F411CE:
```
NRF24L01    ->  STM32F411CE
VCC         ->  3.3V (внутреннее питание)
GND         ->  GND
MOSI        ->  PA7 (SPI1_MOSI)
MISO        ->  PA6 (SPI1_MISO)  
SCK         ->  PA5 (SPI1_SCK)
CSN         ->  PA4 (выход, управление CSN)  
CE          ->  PB0 (выход, управление CE)
```

### Подключение датчиков:
- **Датчик движения PIR** (например, HC-SR501):
  - VCC -> 5V или 3.3V
  - GND -> GND  
  - OUT -> PA1 (вход, подтянут к земле)
- **Геркон-датчик**:
  - Одна ножка подключена к PA1 (вход, подтянут к земле)
  - Другая ножка подключена к GND

## Конфигурация проекта

Файл `include/config.h` содержит основные настройки:

```c
// ===== РЕЖИМ РАБОТЫ ПЛАТЫ =====
// Если (0) — прошиваем Приемник (База + UART)
// Если (1) — прошиваем Передатчик (Датчик)
#define IS_TRANSMITTER 1

// ID модуля
#define NODE_ID 2

// Тип датчика если IS_TRANSMITTER == 1
#define NODE_TYPE_MOTION 1  // PIR, движение
#define NODE_TYPE_OC     2  // геркон, открыто/закрыто

#define NODE_TYPE NODE_TYPE_OC
```

## Сборка проекта

### Требования:
- PlatformIO Core (версия 5.x или выше)
- STM32F411CE Development Board (или аналогичный)

### Команды сборки:
```bash
# Сборка проекта для STM32F411CE (используя PlatformIO)
pio run

# Загрузка прошивки
pio run -t upload

# Мониторинг UART (115200 baud)
pio device monitor
```

## Использование системы

### Роль приемника (IS_TRANSMITTER = 0):
1. Настройте `IS_TRANSMITTER` на 0 в config.h
2. Загрузите прошивку на плату
3. Подключите UART (например, через USB-to-Serial)
4. Приемник будет ожидать данные от передатчиков и выводить их через UART

### Роль передатчика (IS_TRANSMITTER = 1):
#### Для датчика движения:
1. Настройте `IS_TRANSMITTER` на 1 в config.h  
2. Установите `NODE_TYPE = NODE_TYPE_MOTION`
3. Подключите датчик движения PIR к PA1
4. Загрузите прошивку

#### Для геркон-датчика:
1. Настройте `IS_TRANSMITTER` на 1 в config.h
2. Установите `NODE_TYPE = NODE_TYPE_OC`
3. Подключите геркон-датчик к PA1
4. Загрузите прошивку

## Работа с радиомодулем NRF24L01
- Частотный канал: 2476 МГц (вне диапазона Wi-Fi)
- Скорость передачи: 1 Мбит/с
- Мощность излучения: максимальная (0 dBm)
- Используется 5-байтовый адрес для связи

## Примеры вывода через UART
Приемник:
```

ID Датчика: 2
Тип: 1
Статус: ДВИЖЕНИЕ ОБНАРУЖЕНО!
Время отправки: 12345 ms

```

## Требования к аппаратному обеспечению

### Для работы с проектом необходимы:
1. **STM32F411CE Development Board** (или аналогичный)
2. **NRF24L01 радиомодуль** 
3. **Датчик движения PIR (HC-SR501)** или аналог
4. **Геркон-датчик (Reed Switch)**
5. **USB-to-Serial адаптер** для мониторинга UART
6. **Питание 3.3V** для микроконтроллера и радиомодуля

### Схема подключения к питанию:
```
STM32F411CE   ->  NRF24L01
3.3V          ->  VCC (питание модуля)
GND           ->  GND
```

## Ограничения и особенности

1. Все модули используют один канал 2476 МГц для связи
2. Система поддерживает только один тип датчиков в каждой роли
3. Время между отправкой пакетов ограничено задержкой 2 секунды для предотвращения дребезга
4. Для приемника необходимо использовать 115200 baud UART для мониторинга

## Дополнительная информация
- Проект использует HAL (Hardware Abstraction Layer) библиотеку STM32
- Поддержка двух типов датчиков: движение и геркон (открыто/закрыто)
- Система может быть расширена для работы с другими типами датчиков
